\# SIEMTRIX Datasets



These datasets were generated from the SIEMTRIX ICS security testbed and are used for security analysis, detection engineering, and machine-learning experimentation.



\## Files



\- `it\_logs.csv` — IT Zone application and command-related events

\- `dmz\_logs.csv` — DMZ validation and security events

\- `ot\_logs.csv` — OT execution and industrial activity logs



\## Usage



The datasets support:

\- log analysis

\- cross-zone correlation

\- anomaly detection

\- machine-learning model development

\- attack simulation analysis



The data originates from the SIEMTRIX lab/testbed environment and does not represent production systems.
